## About Me

Just an ordinary high school student.

I am a chemistry olympiad competitor, later dabbled in math olympiad, also self-studied physics olympiad and informatics olympiad (learned them terribly), so programming skills are indeed not great.

Accidentally learned Python in grades 2-3 of elementary school, fell in love with programming ever since, ~~to the point that I still don't know Scratch to this day~~. Later, in grades 1 of middle school, got into web development, learning HTML, CSS, and JavaScript. After that, spent time hanging around Minecraft Wiki, and to understand what those Modules were doing, got in touch with Lua, but didn't study it seriously and didn't learn it well. Recently, bothered by Python's slowness and high memory usage, started learning Rust. Unfortunately, my computer's system is Windows 7, newer versions can't install, and older versions installed but won't work. No solution, so I have to use an IDE.

Usually enjoy ~~reinventing the wheel~~ writing simple programs, developing things that people need but almost no one makes. Furthermore, I prefer to craft things by hand, dislikes using ready-made solutions (unless something is truly too difficult), because this gives more freedom, and the program can be fully under my control. ~~Yet in reality, whenever I encounter something I don't know just hand it over to generative AI.~~
