## 關於我

一個普普通通的高中生罷了。

本狐是化競生，後來學了點數競，也自學了物競和信競（學得一塌糊塗），所以編程能力確實不行。

小學二三年級時意外學了 Python ，從此愛上編程，~~以至於到今天還不會 Scratch~~。後來初一的時候接觸了網頁開發，學習了 HTML、CSS 和 JavaScript。再後來，在 Minecraft Wiki 上鬼混，為了看懂那些 Module 在幹嘛，又接觸了一下 Lua，但沒有用心學，沒學好。最近嫌 Python 的速度太慢、記憶體太大，學了一下 Rust，可惜電腦的系統是 Windows 7，新版本裝不了，舊版本裝上用不了，也是沒招了，只能用 IDE。

平常喜歡~~重複造輪子~~寫點簡單程式，開發點有需求但幾乎沒人做的東西。再者，本狐還是喜歡自己手搓點東西出來，不喜歡別人做好的（除非真的太難做了），因為這樣比較自由，程式可以完全被自己掌控。~~然而事實上總是遇到不會的東西就丟給生成式 AI。~~
