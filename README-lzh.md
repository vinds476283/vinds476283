## 自述

一介尋常高中生耳。

本狐嘗修化競，後涉數競，亦自習物競與信競，然皆不精，故編程之技實陋劣矣。

二三年時，偶得 Python，遂嗜編程，~~至今猶不能 Scratch~~。七年時，習網頁之術，通 HTML、CSS 及 JavaScript。其後，遊於 Minecraft Wiki，欲窺 Module 之所為，復觸 Lua，然未專攻，竟無成。近嫌 Python 運算遲而耗內存，乃學 Rust，惜機裝 Windows 7，新版不能載，舊版載而不可用，莫可奈何，惟用 IDE 耳。

平居好~~複造車輪~~撰小程式，以應己需，多為世所忽者。且本狐喜自手造物，不樂假他人已成者（除非至難），蓋自為則隨心所欲，無所束縛。~~然臨困輒委之於生成式AI，實自欺也。~~
