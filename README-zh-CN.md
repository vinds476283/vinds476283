## 关于我

一个普普通通的高中生罢了。

本狐是化竞生，后来学了点数竞，也自学了物竞和信竞（学得一塌糊涂），所以编程能力确实不行。

小学二三年级时意外学了 Python ，从此爱上编程，~~以至于到今天还不会 Scratch~~。后来初一的时候接触了网页开发，学习了 HTML、CSS 和 JavaScript。再后来，在 Minecraft Wiki 上鬼混，为了看懂那些 Module 在干嘛，又接触了一下 Lua，但没有用心学，没学好。最近嫌 Python 的速度太慢、内存太大，学了一下 Rust，可惜电脑的系统是 Windows 7，新版本装不了，旧版本装上用不了，也是没招了，只能用 IDE。

平常喜欢~~重复造轮子~~写点简单程序，开发点有需求但几乎没人做的东西。再者，本狐还是喜欢自己手搓点东西出来，不喜欢别人做好的（除非真的太难做了），因为这样比较自由，程序可以完全被自己掌控。~~然而事实上总是遇到不会的东西就丢给生成式 AI。~~
