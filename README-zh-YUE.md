## 關於我

一個普普通通嘅高中生咋嘛。

本狐係化競生，後來學咗少少數競，自學咗物競同信競（學到一塌糊塗），所以編程能力真係唔得。

小學二三年級嗰陣意外學咗 Python ，從此愛上編程，~~搞到今日都仲未識 Scratch~~。後嚟初一嘅時候接觸咗網頁開發，學咗 HTML、CSS 同 JavaScript。再後嚟，喺 Minecraft Wiki 上邊周圍逛，為咗睇明啲 Module 做緊乜，又接觸咗一下 Lua，但冇用心學，學得唔好。最近嫌 Python 太慢、食 memory 太多，學吓 Rust，可惜電腦嘅系統係 Windows 7，新版本裝唔到，舊版本裝到又用唔到，真係冇晒計，唯有靠 IDE。

平時鍾意~~重複整轆~~寫吓簡單程序，開發啲有需求但幾乎冇人整嘅嘢。再者，本狐仲係鍾意自己手砌啲嘢出嚟，唔鍾意人哋整好嘅（除非真係太難整），因為咁樣比較自由，程序可以完全俾自己掌控。~~但係事實上成日遇到唔識嘅嘢就掉俾生成式 AI。~~
